# Chat en Tiempo Real 💬

Proyecto de un chat en tiempo real hecho con Node.js.

## Qué hace el proyecto
Esta aplicación permite que varios usuarios se envíen mensajes en tiempo real desde el navegador.

## Tecnologías
- Node.js
- Socket.io
- HTML
- CSS
- JavaScript

## Cómo se ejecuta
1. Abrir la carpeta del proyecto.
2. En la terminal escribir:
   npm install
3. Luego:
   node index.js
4. Abrir en el navegador:
   http://localhost:3000
